# e-Tasmik

Static GitHub Pages package for the e-Tasmik web app. The deployment workflow publishes the app from the `site/` directory when changes are pushed to `main`.

This public package intentionally uses empty student and teacher roster files. It does not include school spreadsheets, student or teacher names, Apps Script source, or local records. Connect the app to an appropriately access-restricted Google Apps Script web app through **Tetapan** after deployment.

If GitHub requests a Pages source, choose **Settings → Pages → Build and deployment → GitHub Actions**.
